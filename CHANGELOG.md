# Changelog

All notable changes to OnTrack are documented in this file.

## [1.0.3] - 2026-09-20

### Fixed

- Fixed stale offline cache updates that could prevent the app from loading after deployment.

## [1.0.2] - 2026-09-20

### Added

- Added an in-app change log viewer.

## [1.0.1] - 2026-09-20

### Changed

- Moved the import and export controls above the weight-entry history.
- Made import and export button typography consistent.

## [1.0.0]

### Added

- Initial OnTrack release with local weight tracking, trend charts, JSON backup import/export, and offline support.
